Minimax H3 影像生成

ComfyUI workflow・角色一致性調校・成本優化

目前在用 ComfyUI 跑 Minimax H3 做 VFX，已經有幾顆鏡頭進到實際案子。被交辦的工作大多是換臉／換動作，最大的卡點是角色一致性——當待替換角色跟參考圖特徵太接近時，模型分不清楚「這是誰」。

解法是把「輸出」反過來當「輸入」用：故意把角色造型誇張化生成一版，拿這版特徵被拉開的結果當新參考圖重新餵回去；或是從堪用影片截圖，丟圖像 AI 做細部修正，再把處理過的圖當首幀餵回影片生成流程。

純t2v，三方陣營辨識，明軍／清軍／百姓，若prompt下的太模糊，會導致所有人都綁上辮子，在prompt前面加入角色定位區隔，同畫面三種身份不會混淆，在minimax h3有不錯的效果

UE 資產 Migrate 架構

C++／Slate・RAII・拓樸排序 + BFS

UE 內建的資產遷移功能（Content Browser 的 Migrate，底層是 AssetTools 模組的 MigratePackages，依賴查詢則呼叫 Asset Registry 的 GetDependencies）會漏掉依賴——查詢查得到，實際搬移時卻搬不動，問題出在遷移邏輯本身。重寫時用一個 RAII 物件包住整次 migrate 操作的生命週期：按下 Migrate 建立物件，操作結束物件離開作用域就自動釋放暫存狀態。

物件內部先用 BFS 走訪資產依賴圖，一次建構三張表——拓樸排序後的順序表、名稱對應實際位置的表、名稱對應是否可安全複製的表。真正搬移時只需要照順序表迭代，逐一確認可複製性、查出位置、執行複製。

Blender MCP 場景生成

Claude + Blender MCP 橋接・Meshy AI 資產生成・單日產出

用 Blender MCP 橋接讓 Claude 直接操作 Blender，搭配 Meshy AI（meshy-6）生成 3D 資產。單日內（21:43 到隔日 00:12）產出 25 項資產——建築、地面、牆面、街道家具、載具、雜物植被六大類——組裝成一個頹敗城市街角場景「decayed_city_corner」，並輸出測試渲染驗證完成度。

另外把公司內部原有的資產瀏覽器魔改，讓它能接收 agent 發出的 API 請求，並調用 client 把資產交給 agent 使用。UX 端則讓 client 端自動生成一段 prompt、注入對應的 API 說明，使用者只要把這段複製給 agent，agent 就能直接調用公司內部的資產庫。
